# DS & AI Journey

My 24-week self-study journey from Python beginner to building and deploying Data Science, Machine Learning and Generative AI projects.

**Goal:** build strong practical foundations in Python, SQL, statistics, ML, deep learning, LLMs and deployment, and finish with a portfolio of 6-8 reproducible projects.

## Repo structure

- `notes/` : my own explanations, one file per week
- `practice/` : small exercises and daily programs
- `projects/` : numbered portfolio projects, each with its own README
- `progress/` : tracker, mistakes log and weekly assessments
- `datasets/` : dataset sources and licenses (large files are not committed)
- `resources/` : useful links

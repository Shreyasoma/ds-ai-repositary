## chai_sales.csv

- **Path:** `datasets/chai_sales.csv`
- **Source:** Created by me as sample data for the Ravi chai-stall exercise (synthetic, not real sales)
- **License:** Own work, free to use
- **Date added:** 2026-10-29
- **Row meaning:** one row per day of sales at the stall

| Column | Meaning | Unit / values |
|--------|---------|---------------|
| date | Day of sales | YYYY-MM-DD |
| cups_sold | Cups of chai sold that day | count |
| milk_used_litres | Milk used that day | litres |
| ran_out | Did the stall run out of milk? | yes / no |

**Notes:**
- `ran_out = yes` rows are censored: sales understate true demand on those days.
